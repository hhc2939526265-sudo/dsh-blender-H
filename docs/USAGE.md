# 使用说明书

## 一、功能总览

| 模块 | 能力 |
|---|---|
| 图片驱动建模 | 单 / 多图上传预览，三档面数精度，面部形状键、服装分层、发型面片、UV 展开、PBR 烘焙、骨骼自动绑定 |
| 视频驱动动画 | 21+ 关节轨迹复刻、帧率匹配、平滑降噪、走跑跳循环、物理模拟、路径约束 |
| 特效还原 | 粒子 / 辉光 / 流体 / 形变 / 镜头运动映射为可编辑节点与系统 |
| 自然语言建模 | 中文提示词解析为内置指令集，35+ 建模操作 |
| 材质渲染 | PBR 节点树生成、批量材质管理、预设存取、Eevee / Cycles 切换、成品回传预览 |
| 反向迭代 | 模型 / 动画 / 材质 / 场景一键回传 DSH，支持多轮优化 |
| 插件生态 | 识别已启用第三方 Addon，按能力归类、发现算子，自然语言匹配并安全调用 |
| 稳定性 | 自动备份回滚、分级日志、指令校验、分批内存管理、闲置缓存释放 |

## 二、标准工作流

1. **启动 Blender 端**：侧边栏 `DSH Bridge` → `启动桥接服务`。
2. **连接 DSH 端**：面板顶栏核对地址端口 → `连接`，状态灯变绿。
3. **输入素材 / 提示词**：上传图片 / 视频，或在自然语言页输入描述。
4. **执行生产**：点击对应执行按钮，日志面板实时查看通信与执行过程。
5. **预览与回传**：渲染成品 / 资产自动回传，在预览区查看。
6. **迭代优化**：在 Blender 侧调整后点击「回传当前资产」，回到 DSH 继续 AI 优化。

## 三、图片建模操作指南

1. 切换到「图片建模」页签。
2. 拖拽或点击上传人物照片（JPG / PNG / WEBP，可多张），缩略图可单独移除。
3. 选择建模精度：`低`（快速预览）/ `中`（平衡）/ `高`（高精度细分）。
4. 点击 `生成 3D 角色并绑定`：
   - 图片分片上传并做 MD5 校验；
   - AI 解析体型比例、五官、服装、发型；
   - 生成标准人体拓扑、面部形状键、服装 / 发型分层；
   - 自动完成原点归位、法线统一、UV 展开、基础 PBR 材质；
   - 生成标准人形骨骼并自动分配权重。
5. 结果元信息（顶点数、形状键数量、骨骼数、AI 后端）显示在右侧结果区。
6. 在 Blender 中可直接编辑网格、权重、形状键与材质，再通过「回传当前资产」进入下一轮迭代。

## 四、视频动画 / 特效复刻指南

1. 切换到「视频动画 / 特效」页签。
2. 上传动作或特效视频（MP4 / WEBM / MOV）。
3. 选择复刻类型：
   - `动作捕捉复刻`：提取关节轨迹对齐当前角色骨骼；
   - `特效还原`：识别粒子 / 辉光 / 流体 / 形变 / 镜头并映射为节点；
   - `动作 + 特效`：两者同时执行。
4. 调整置信度阈值与特效还原强度，点击 `解析并复刻到角色`。
5. 关键帧可在 Blender 时间轴二次编辑；时序支持全局变速与局部调速。

## 五、第三方插件协作指南

桥接可与 Blender 中已安装并启用的第三方插件协同工作：自动识别插件作用、列出其可用算子，
按意图匹配后直接调用，结果回到当前场景继续生产。

1. **前置条件**：先在 Blender 偏好设置中启用目标第三方插件（未启用的插件算子未注册，无法被发现）。
2. **识别插件**：切换到「插件生态」页签，点击 `刷新插件列表`，左侧列出全部已启用第三方插件，
   卡片显示名称、能力分类标签、版本与算子数量。
3. **查看详情**：点击插件卡片，右侧展示作者、类别、描述与算子列表；每个算子标注参数名、类型与是否必填。
4. **意图匹配**：在顶部输入框描述需求（如「自动给角色绑定骨骼并分配权重」「生成火焰粒子」），
   点击 `匹配插件`，按命中词数排序返回最相关插件，点击结果直接跳转详情。
5. **调用算子**：在算子列表点击目标算子自动填入算子 ID；按需在参数框填写 JSON 参数，
   选择 `直接执行` 或 `交互面板`，点击 `调用算子`，回执显示在下方结果区。
6. **参数格式**：参数为 JSON 对象，仅支持字符串 / 数字 / 布尔 / 原始类型数组，例如
   `{"target": "Character", "count": 3, "use_mirror": true}`。
7. **安全说明**：所有调用经过算子存在性校验、参数类型白名单过滤、算子前缀白名单与危险算子黑名单校验，
   异常收敛为失败回执，不会拖垮 Blender；可在配置 `allow_addon_invoke` 中关闭第三方算子调用权限，
   通过 `addon_operator_allowlist` / `addon_operator_denylist` 进一步收窄可调用算子范围。

> 能力识别基于插件 `bl_info` 元信息与关键词归类；如需更深语义理解，可在 AI 适配层接入大模型对描述做二次解析。

## 七、历史与预设

- **内置模板**：历史预设页签提供 17 个场景模板，点击即套用对应参数并跳转页签。
- **执行历史**：每条指令记录时间、类型、回执结果，可回看；本地保留最近 200 条。
- **复用**：后续版本支持点击历史记录一键重放当前指令序列。

## 八、日志面板

- 四级日志：`DEBUG / INFO / WARNING / ERROR`；
- 顶部下拉按级别筛选；`导出日志` 下载本地文本；`清空日志` 清除面板记录；
- Blender 端同时把日志写入按天滚动的本地文件，保留 14 天。

## 九、暂停 / 停止

- `暂停队列`：本地状态提示（队列串行模式下可结合 Blender 面板「清空指令队列」使用）；
- `停止当前任务`：向 Blender 发送 `system.stop`，清空排队中尚未执行的指令，已落地的修改不受影响；
- 复杂建模前若开启「自动备份」，可通过 `scene.rollback` 一键回滚。
