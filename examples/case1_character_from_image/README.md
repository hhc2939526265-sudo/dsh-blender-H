# 案例 1：单张人物图片生成 3D 角色 + 自动绑定全流程

## 目标

上传一张正面人物照片，在 Blender 中得到：标准化人体网格、面部形状键、
服装 / 发型分层、基础 PBR 材质、标准人形骨骼与自动权重，且全部资产可二次编辑。

## 前置条件

- Blender 4.2 ~ 5.3 已安装并启用 DSH Bridge Addon，服务已启动；
- DSH 端插件已连接；
- 准备一张清晰正面人物照片（JPG / PNG / WEBP）。

## 操作步骤

1. DSH 面板「图片建模」页签上传照片，选择精度 `高`。
2. 点击 `生成 3D 角色并绑定`，等待分片上传与建模完成。
3. 切换到 Blender，查看生成的 `Character_Body`、服装分层、`Hair` 与 `Character_Rig`。
4. 姿态模式拖动骨骼验证权重；编辑形状键做表情；调整材质节点。

## 指令序列（commands.json）

见同目录 `commands.json`。高层指令由 DSH 端自动完成图片分片上传后，把落盘路径
填入 `image_paths`。

## 预期结果

- 身体网格顶点数随精度档位变化，法线统一、UV 已展开、原点位于几何中心；
- 面部形状键 50+ 个，均可在形状键面板拖动编辑；
- 骨架包含 21+ 标准人形骨骼，身体已完成自动权重绑定；
- 皮肤 / 服装 / 发型材质挂载完成，基础色取自参考图平均色。

## 验收要点

- [ ] 角色模型在 Blender 中可见且无破面 / 反法线；
- [ ] 骨骼可驱动肢体摆动；
- [ ] 材质节点树可编辑；
- [ ] 回执 `result` 含 `body / rig / shape_keys / vertices` 字段。
