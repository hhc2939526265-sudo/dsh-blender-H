# 案例 2：参考视频复刻人物行走动画 + 光效粒子特效

## 目标

上传一段人物行走视频，复刻主体动作轨迹到当前角色骨骼，并还原参考视频中的
粒子与辉光特效，最后生成推轨镜头并渲染回传。

## 前置条件

- 已完成案例 1（场景中存在带骨架的角色）；
- 准备一段正面 / 侧面行走视频（MP4 / WEBM / MOV）；
- DSH 与 Blender 桥接已连接。

## 操作步骤

1. 「视频动画 / 特效」页签上传视频，复刻类型选择 `动作 + 特效`。
2. 置信度保持 0.6，特效强度 0.8，点击 `解析并复刻到角色`。
3. 查看时间轴：骨骼关键帧与原视频帧率对齐，循环无缝。
4. 查看特效：角色周边生成粒子系统与发光辉光材质，合成器接入辉光节点。
5. 执行推轨镜头匹配，渲染静帧并回传预览。

## 指令序列

见同目录 `commands.json`。

## 预期结果

- 21+ 关节轨迹落到骨架对应骨骼，首末帧对齐可循环；
- 粒子数量 / 速度 / 生命周期 / 颜色渐变与特效规格一致；
- 辉光材质自发光强度与颜色可调节，合成辉光节点生效；
- 摄像机动画完成推轨，渲染成品自动回传 DSH 预览区。

## 验收要点

- [ ] 动作轨迹主体还原度 ≥ 80%，关键帧可二次编辑；
- [ ] 粒子 / 辉光参数在 Blender 中可调整；
- [ ] 渲染图 / 视频通过分片回传且 MD5 校验一致；
- [ ] 回执含 `motion` 与 `effect` 两段结果。
