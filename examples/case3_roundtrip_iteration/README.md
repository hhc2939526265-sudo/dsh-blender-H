# 案例 3：Blender 修改后回传 DSH 二次优化迭代全流程

## 目标

演示反向链路闭环：Blender 中调整资产 → 一键回传 DSH → AI 基于回传结果继续
优化建模 / 材质 / 动画 → 再次回传，连续至少 3 轮数据无丢失。

## 前置条件

- 场景中已有角色 + 动画（案例 1 / 2 产物均可）；
- 桥接连接正常。

## 迭代流程

### 第 1 轮：Blender → DSH 回传

1. 在 Blender 中对角色做一轮手工调整（倒角 / 权重 / 材质）。
2. DSH 面板点击 `回传当前资产`，或发送 `pipeline.iterate`。
3. 资产 glb、动画轨迹 JSON 分片回传，DSH 预览区与历史记录留存。

### 第 2 轮：DSH → AI 优化 → 下发 Blender

1. DSH 基于回传资产生成优化指令（倒角、材质参数、动画节奏调整）。
2. 指令逐条下发 Blender 落地，结果再次回执。

### 第 3 轮：再次回传确认

1. 再次 `pipeline.iterate` 回传，对比三轮回执中的顶点数 / 材质 / 关键帧数量。
2. 全程历史可追溯，数据无丢失。

## 指令序列

见同目录 `commands.json`。

## 预期结果

- 每轮回传均包含资产 glb 与动画轨迹 JSON，MD5 校验通过；
- 优化指令在 Blender 侧成功落地并回传回执；
- 历史记录保留三轮条目，可回看每轮结果。

## 验收要点

- [ ] 至少 3 轮迭代数据完整，无丢失；
- [ ] 回传文件可在 DSH 预览 / 重新导入 Blender；
- [ ] 迭代轮次计数正确（iteration 1 → 2 → 3）。
