# 案例 4：仙侠打斗镜头（姿态 + 武器跟随 + 能量特效 + 镜头震动）

## 目标

在已有带骨架角色与武器的场景中，组装一段仙侠打斗镜头：战斗姿态 → 武器跟手 →
剑气拖尾 / 灵气光环 / 护盾 → 火花碎片 → 冲击波 → 雷弧 → 镜头震动，最后渲染回传。

## 前置条件

- 已完成案例 1（场景中存在 `Character_Rig` 骨架与 `Character_Body` 网格）；
- 场景中已有武器对象 `Sword`（可用 `mesh.add_primitive` / `mesh.curve` 拼接）；
- DSH 与 Blender 桥接已连接。

## 操作步骤

1. 用 `anim.pose` 写入起手挥剑姿态，骨骼关键帧可在时间轴二次编辑。
2. 用 `anim.follow_target` 让武器跟随右手骨骼；`material.emission` 给剑身附光。
3. 依次叠加剑气拖尾、灵气光环、能量护盾。
4. 命中阶段触发火花粒子与碎石刚体，随后环形冲击波扩散。
5. 两点之间生成雷弧，镜头按幅度震动，渲染静帧回传预览。

## 指令序列

见同目录 `commands.json`。

## 预期结果

- 骨骼姿态与武器跟随在 Blender 内可继续调帧；
- 拖尾 / 光环 / 护盾 / 冲击波 / 雷弧 / 火花 / 碎片参数均可二次调整；
- 镜头震动关键帧可编辑；渲染成品分片回传且 MD5 校验一致。

## 验收要点

- [ ] 姿态骨骼旋转 / 位置关键帧落到对应骨骼；
- [ ] 武器随手部骨骼运动，脱离后可解除约束；
- [ ] 能量特效材质发光强度 / 颜色可调，合成节点生效；
- [ ] 碎片以刚体参与解算，冲击波半径时序正确；
- [ ] 本案例为参数化脚手架，最终视觉质量取决于真机资产与外部 AI 解析结果。
